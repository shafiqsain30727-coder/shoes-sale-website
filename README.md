# SoleMate — Shoes Sale Website

A polished, responsive shoe store landing page with a working product filter, shopping bag, local storage persistence, newsletter interaction, and mobile navigation.

## Run locally

Open `index.html` in any modern browser. The site uses Google Fonts and Unsplash image URLs, so an internet connection is recommended for the full visual experience.

## Customize

- Edit the `products` array in `script.js` to change shoes, prices, categories, and images.
- Update colors and layout in `style.css`.
- Replace the checkout alert in `script.js` with your payment provider or order API.
